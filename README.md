# Yalın Rota

Corporate website for Yalın Rota, built as a responsive Vite multi-page frontend.

## About

Yalın Rota is an independent web development studio offering web solutions for small and medium-sized businesses in Türkiye. Services include corporate websites, website renewal, custom web development, and technical support.

## Tech

- React
- TypeScript
- Vite
- Tailwind CSS

## Development

Install dependencies and start the development server:

```sh
npm install
npm run dev
```

Create a production build (includes TypeScript checking):

```sh
npm run build
```
